About Us


Uncle Bro’s Coffee is a simple college project made to promote a coffee shop website.


It shows different coffee products and provides basic information about the shop. As college students, we created this website using HTML and CSS.


This project helped us learn how to design a webpage, improve our web development skills and showed us how a website can be used to promote a business.
